# AutoSwap Mod (Fabric, Minecraft 1.21.11)

Фабрик-мод для Minecraft, который упрощает работу с предметами: свап в offhand, элитры, воздушные заряды и булава.

## Возможности

### Клавиша `F` — быстрый свап предмета в offhand
1. Открой инвентарь (`E`).
2. Нажми кнопку **«Выбрать предмет»**.
3. Наведи на нужный предмет и нажми **ЛКМ** — инвентарь закроется, предмет запомнится.
4. Жми `F` — предмет встанет в **offhand**. Повторно `F` — вернётся обратно.

### Клавиша `G` — нагрудник ↔ элитры
Меняет элитры в нагруднике на текущий нагрудник и обратно (ищет элитры в инвентаре).

### Клавиша `X` — воздушный заряд
Берёт воздушный заряд в руку, кидай его (ПКМ), и он автоматически вернётся прежний предмет в руку.

### Авто: булава (mace)
Если падаешь больше **3 блоков** — автоматически берёт булаву в руку (для скейк-атаки). При приземлении возвращает прежний предмет.

## Установка
1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft **1.21.11**.
2. Установи [Fabric API](https://modrinth.com/mod/fabric-api) версии для 1.21.11.
3. Скачай `autoswap-1.0.0.jar` из папки `builds/`.
4. Положи `autoswap-1.0.0.jar` в папку `mods/` в директории игры.
5. Запусти игру через Fabric-профиль.

## Настройка клавиш
Клавиши можно изменить в **Настройки → Управление → категоря AutoSwap**.

- `F` — выбрать/свапнуть предмет
- `G` — нагрудник ↔ элитры
- `X` — воздушный заряд

## Сборка из исходников
```bash
./gradlew build
```
Готовый mod будет в `build/libs/`.

Требуется Java 21.
